# Forms

## What is Logiks Forms?

Logiks Forms is a **JSON-driven dynamic form engine** in LRC that enables building fully functional forms without writing UI code.

It supports:

- Dynamic rendering
- API/SQL integrations
- Field dependencies
- Validation & persistence
- Workflow hooks

---

## Key Capabilities

- Declarative JSON configuration
- Dynamic data binding
- Multi-source data (API / SQL / static)
- Rich field types
- Event hooks (pre/post submit)
- Auto-fill via session and context

---

## When to Use

Use Logiks Forms when:

- You want configurable forms without frontend coding
- You need dynamic data-driven inputs
- You want reusable form definitions across modules
