# Persistence

## Persistent Fields

```json id="persistent-true"
"persistent": true
```

Stores values locally and reuses them when reopening form.

---

## Custom Key

```json id="persistent-key"
"persistent": "user_name"
```

---

## Behavior

- Works in **add mode**
- Pre-fills previously entered values
- Stored per module reference
