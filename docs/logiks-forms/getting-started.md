# Getting Started

## Minimal Form Example

```json id="basic-form"
{
  "template": "simple",
  "fields": {
    "name": {
      "type": "text",
      "label": "Name",
      "required": true
    }
  }
}
```

---

## Steps to Create a Form

1. Define `template`
2. Configure optional `source` (for edit mode)
3. Add `fields`
4. Add optional `forcefill`
5. Configure `gotolink`
